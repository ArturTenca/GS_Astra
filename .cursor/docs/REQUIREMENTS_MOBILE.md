Mobile — Global Solution
Requisitos técnicos
Criação de um aplicativo mobile alinhado ao tema da Global Solution, utilizando:

React Native com Expo

Opcional: integração com Firebase, API externa ou armazenamento local.

Elementos obrigatórios
• Construção da Interface Mobile — 20 pontos
O aplicativo deve possuir telas organizadas, navegação funcional e layout compatível com dispositivos móveis.

Exemplos de telas:

Tela inicial
Tela de cadastro/registro
Tela de listagem
Tela de detalhes
Tela de confirmação/status
• Navegação e Fluxo de Uso — 20 pontos
O app deve permitir que o usuário percorra um fluxo completo relacionado ao tema da Global Solution.

Exemplo:

Informar uma ocorrência
Consultar dados
Registrar uma ação
Visualizar histórico
Receber uma resposta do sistema
• Manipulação de Dados — 15 pontos
O aplicativo deve trabalhar com dados reais ou simulados.

Pode utilizar:

Estado local
AsyncStorage
Firebase
API externa
Arquivos JSON
Os dados devem ser exibidos de forma clara no app.

Requisitos técnicos — continuação
• Recursos Mobile — 15 pontos
O projeto deve utilizar pelo menos um recurso nativo ou característico de mobile, como:

Câmera
GPS/localização
Notificações
Leitura de código de barras/QR Code
Galeria de imagens
Sensor do dispositivo
• Tratamento de Erros e Validações — 10 pontos
O app deve validar entradas do usuário e evitar falhas durante o uso.

Exemplos:

Campos obrigatórios
Mensagens de erro
Tratamento de permissão negada
Falha ao carregar dados
Registro não encontrado
• Organização do Projeto — 20 pontos
Será avaliado:

Estrutura de pastas
Nome adequado de arquivos, telas e componentes
Separação entre tela, componentes e serviços
Código limpo e legível
README explicando o projeto
Evidências de execução do app
Entrega
A entrega deve conter:

Código-fonte do projeto
README com objetivo, tema e instruções de execução
Vídeo curto do app funcionando
Descrição do recurso mobile utilizado
Link do repositorio git

Obrigatório: sem evidências de execução, haverá desconto na nota.
