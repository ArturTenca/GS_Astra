Desafio de Cybersecurity: Global Solution - 1º
Semestre 2026

Objetivo: Integrar uma camada de segurança sólida à solução proposta, garantindo que o ecossistema
espacial (ou terrestre, dependendo da sua abordagem) opere de forma resiliente, confiável e em
conformidade com as melhores práticas de mercado.
Para esta entrega, o grupo deverá realizar uma análise profunda da segurança necessária para sustentar a
inovação proposta. A segurança não deve ser vista como um entrave, mas como o alicerce que permite que
os dados espaciais e as novas tecnologias criem impacto real na sociedade.
Entregáveis Esperados
O grupo deve estruturar o capítulo de Cybersecurity abordando os seguintes pilares:
1. Análise de Riscos e Ameaças (Threat Modeling)
Identificação de Ativos (1 ponto): Liste quais são os dados críticos e infraestruturas (ex: links de
satélite, bases de dados, sensores) que sua solução manipula.
Modelo de Ameaças (1 ponto): Identifique pelo menos três vetores de ataque plausíveis para sua
solução (ex: interceptação de dados, manipulação de telemetria, indisponibilidade de serviço/DDoS).
2. Arquitetura de Segurança (Controles)
Controles de Acesso (1 ponto): Como será garantido que apenas usuários/sistemas autorizados
acessem os dados? (Ex: Autenticação de múltiplos fatores, privilégio mínimo).
Proteção de Dados (1 ponto): Como os dados serão protegidos em trânsito e em repouso? (Ex:
Criptografia, anonimização, hashing).
Segurança da Infraestrutura (1 ponto): Quais tecnologias serão usadas para assegurar que o sistema
seja íntegro? (Ex: Arquitetura Zero Trust, firewalls, monitoramento de logs).
3. Governança e Compliance
Alinhamento Normativo (1 ponto): Baseado nos princípios da ISO 27001, descreva como o projeto
tratará a Gestão de Riscos e a Segurança da Informação.
Privacidade (1 ponto): Como a solução garante a proteção de dados (seguindo a LGPD ou princípios
similares), especialmente se envolver dados de localização ou comportamentais?
4. Plano de Resiliência e Continuidade
Plano de Resposta a Incidentes (3 pontos): O que acontece se o sistema sofrer uma invasão?
Descreva brevemente os passos de contenção, erradicação e recuperação para manter a solução
operacional.
